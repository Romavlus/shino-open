# Shino Open

Сино — анимированный персонаж для рабочего стола macOS. В сборку входят три образа, три походки и двадцать сценок. Значок с бантом в строке меню открывает примерочную. В ней можно повернуть персонажа мышью, приблизить колёсиком и поставить движение на паузу.

## Скачать для macOS

[Shino Open 1.3.0 для Apple Silicon](https://github.com/Romavlus/shino-open/raw/refs/heads/main/Downloads/Shino-Open-1.3.0-macOS-arm64.zip). Требуется macOS 13 или новее. Это тестовая сборка с локальной подписью ad hoc.

## Сборка на Mac

Нужны macOS 13 или новее, Python 3 и инструменты командной строки Xcode. Команды из корня проекта собирают приложение для архитектуры текущего Mac и открывают примерочную. Все модели, движения и библиотеки для сборки входят в проект.

```sh
python3 build.py --output "$HOME/Applications/Shino Open.app"
open "$HOME/Applications/Shino Open.app" --args --studio
```

Скрипт подписывает приложение локальной подписью ad hoc. Проверки переключения образов и поведения на рабочем столе можно запустить отдельно.

```sh
"$HOME/Applications/Shino Open.app/Contents/MacOS/Shino" --verify-models
"$HOME/Applications/Shino Open.app/Contents/MacOS/Shino" --verify
```

## Первый запуск

При первом запуске Сино машет рукой. Нажмите «Попробовать движения», чтобы открыть примерочную. В разделе «Поведение» можно выбрать русский, английский или язык системы. Перетащите Сино туда, где она должна появляться при запуске. Программа сохраняет выбранное место, в том числе у нижнего края экрана.

Локальный ZIP предназначен для Apple Silicon. Распакуйте его, перенесите Shino Open.app в папку приложений и откройте. Тестовая сборка подписана ad hoc. Для обычного запуска скачанного релиза через Gatekeeper ещё нужны подпись Developer ID и нотариализация Apple.
